# Dungeon Legends — калькулятор урона

Монте-Карло калькулятор урона для нашей домашней редакции D&D: выбираете расу, класс,
способность, модификаторы и цели — получаете распределение урона, среднее, шанс попадания
и сравнение всех способностей героя между собой.

**Живая версия: https://djaler.github.io/dungeonlegends-calculator/**

Правила, по которым считает калькулятор, лежат в [docs/rules.md](docs/rules.md).

## Разработка

Зависимостей нет — нужен только Node.js 22+.

```sh
npm test        # node --test, весь набор тестов в test/
node build.js   # собирает dnd-dmg.html из src/ и template.html
```

Собранный `dnd-dmg.html` — самодостаточная страница, её можно просто открыть в браузере.
В репозиторий она не коммитится: её собирает CI.

## Как устроена сборка

`build.js` — не бандлер, а конкатенатор: он вырезает `import`/`export` из модулей `src/`
и склеивает их в один скоуп, поэтому порядок файлов в нём важен. Результат подставляется
в `template.html` на месте маркеров `/*ENGINE*/` и `/*UI*/`.

Симуляция крутится в Web Worker, чтобы не блокировать интерфейс. Код воркера — тот же
движок: `build.js` сериализует его в строку и создаёт Worker из `Blob`, так что отдельного
файла воркера не существует.

- `src/engine.js` — броски костей, детерминированный ГПСЧ, преимущество/помеха
- `src/characters.js` — расы, классы, характеристики, пресеты целей
- `src/abilities/` — способности, по файлу на класс
- `src/modifiers.js` — модификаторы и правила их применимости
- `src/simulator.js` — прогон Монте-Карло и сравнение способностей
- `src/ui-logic.js`, `src/ui.js` — состояние и рендер интерфейса

## Деплой

Пуш в `main` запускает [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml):
прогоняются тесты, собирается страница и публикуется на GitHub Pages.
Настройка Pages — **Settings → Pages → Source: GitHub Actions**.
