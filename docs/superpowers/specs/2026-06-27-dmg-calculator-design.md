# Калькулятор урона — орк-волшебник (наша редакция ДнД)

Дата: 2026-06-27
Статус: дизайн утверждён, готов к плану реализации

## Цель

Инструмент, помогающий рассчитывать наносимый урон в разных боевых ситуациях
(класс брони цели, число противников, их HP) для персонажа **орк-волшебник**,
с расширяемой архитектурой под другие классы/расы в будущем.

## Форм-фактор

Один самодостаточный файл `dnd-dmg.html` (HTML + CSS + JS в одном файле, без
интернета, без установки). Открывается двойным кликом в браузере, в том числе
**на телефоне**. Никаких внешних зависимостей, CDN, шрифтов — всё инлайн.

## Движок расчёта

**Монте-Карло** — выбран ради расширяемости: один простой код считает все метрики,
любая условная логика правил пишется буквально, новые способности/классы
добавляются без вывода формул.

- 100 000 прогонов по умолчанию.
- Фиксируемое зерно ГПСЧ → детерминированный режим (для проверки) + кнопка
  «перетряхнуть» для нового сэмпла.
- Расчёт в **Web Worker**, чтобы UI не подвисал.
- Запасные рычаги, если где-то станет тяжело: снизить число прогонов (20 000 →
  погрешность ~0.2 урона, скорость ×5).

## Архитектура (3 слоя, данные отделены от логики)

1. **Движок** — чистые функции: `rollD20()`, `rollDamageDie(sides)` с орочьим
   перебросом «1–2» («Рождённый в битве»), обёртки преимущество/помеха, криты
   (крит на натуральной 20). Не знает о конкретных способностях.
2. **Описания способностей** — массив объектов. Каждая способность реализует
   `simulateOnce(ctx) → { damageByTarget }`. Добавить способность = дописать один
   объект; движок и UI не трогаются.
3. **Симулятор + UI** — гоняет выбранную способность N раз, агрегирует 4 метрики,
   рисует мобильный интерфейс.

Плюс **лёгкий справочник** базовых характеристик классов и рас (только базовая
Броня/Здоровье + расовые правки) — используется **только** для пресетов целей,
отдельно от боевой логики волшебника.

## Важная деталь правил (учтена)

Орочья слабость «+2 к магическому урону» — это **получаемый** урон (уязвимость к
магии), а **не** прибавка к исходящему урону волшебника. На наш расчёт исходящего
урона она НЕ влияет. Реально влияет «Рождённый в битве»: переброс «1–2» на каждом
кубике урона — включён по умолчанию, есть тумблер выключения.

## Покрываемые способности (орк-волшебник)

- **Волшебные снаряды** — 3 × (1д4+1), автопопадание, без бросков.
- **Цепная молния** — 2д6 авто по 1-й цели; затем до 3 дальнобойных атак
  (д20+Интеллект) по следующим целям, цепь рвётся при первом промахе. Учитывает
  КБ целей и их количество.
- **Огненный шар** — 6д6 по площади; каждая цель проходит спасбросок (д20+Ловкость
  ≥ 15), при провале полный урон, при успехе половина. Главный инструмент по толпе.
- **Телекинез** — 1д4 атака (для полноты).
- **Базовая атака посохом** — 1д4 (+владение посохом).
- **Модификаторы-переключатели:** Концентрация (+2д6 к следующему магическому
  урону), зелье хаоса (×2 магический урон), преимущество/помеха, Сглаз (помеха
  атакам цели), орочий переброс «1–2».

## Цели (вход)

Вместо одного поля «число врагов» — **список целей**, каждую можно добавить/удалить.
У каждой цели независимо задаются **КБ** и **HP** двумя способами:

1. **Вручную** — вписать КБ и HP.
2. **Пресет «раса + класс + уровень игры»** — подставляет расчётные КБ и HP,
   которые затем можно подправить вручную.

Логика пресета (оценка из правил):
- **HP** = базовое HP класса + расовая правка HP (орк +5, полурослик −5, …)
  + 5 за каждую пройденную веху прокачки (игры 4/8/12/16/20).
- **КБ** = базовая броня класса + расовая правка брони (драконорождённый +1, …).

Оговорка (принята пользователем): пресет даёт **базовую оценку**; боевые баффы
брони/HP (ярость варвара, формы друида, божественная кара паладина и т.п.) НЕ
учитываются. Для прикидки «пробью ли я» этого достаточно.

Площадные способности (огненный шар) бьют по всем целям списка; одноцелевые — по
выбранной; цепная молния — по цепочке из списка.

## Выход (4 метрики)

1. **Ожидаемый урон** — по одной цели и суммарный по группе.
2. **Разброс** — мин/макс, гистограмма, «шанс нанести ≥ X», «шанс убить цель с
   N HP за ход».
3. **Сравнение способностей** — таблица всех способностей в текущей ситуации,
   отсортированная по ожидаемому урону, с пометкой расхода зарядов (3 раза в бой и
   т.п.).
4. **Урон по группе** — суммарный по всем целям из списка.

## Мобильный UI (mobile-first)

- Одноколоночный поток; крупные тач-цели (степперы/ползунки вместо мелких полей).
- Блок результатов — наверху, «липкий» (sticky), всегда виден при кручении настроек.
- Гистограмма и таблица сравнения скроллятся внутри своих блоков; страница не
  скроллится горизонтально.
- Проверка на узкой ширине (~360px) перед сдачей.

## Вне рамок первой версии (YAGNI)

- Другие классы как играбельные персонажи (только справочник для пресетов целей).
- Небоевые способности, лечение, контроль без урона (кроме Сглаза как модификатора).
- Сохранение/загрузка пресетов персонажа между сессиями (можно добавить позже).
